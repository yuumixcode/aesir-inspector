# Aesir Inspector

[![license](https://img.shields.io/badge/license-MIT-green.svg)](LICENSE.md)

依赖 Odin Inspector，提供基于 Odin Inspector 扩展功能。

## Installation

Open the Package Manager window in Unity, click the `+` button in the top-left corner, and select `Add package from git URL...`. Enter:

```
https://github.com/RunLabTeam/aesir-inspector.git
```

Or add the following to your `Packages/manifest.json`:

```json
"com.runlab.aesir-inspector": "https://github.com/RunLabTeam/aesir-inspector.git"
```
